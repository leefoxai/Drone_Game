# 데이터·학습 도구 자리

M3에서 Python으로 소수 랩 리렌더 결과를 검사하고 작은 BC(행동 모방) 모델을 학습한다.
M6에서 대량 렌더 작업·라벨 검사·큐레이션을, M7에서 PyTorch 학습과 ONNX 내보내기를 추가한다.
현재 실행 가능한 Python 도구나 설치할 Python 패키지는 없다.

가상 환경은 저장소 루트에서 `python -m venv .venv`로 만든다.
PowerShell에서 활성화하지 않고 `.\.venv\Scripts\python.exe`로 직접 실행해도 된다.
학습 시점에 PyTorch가 지원하는 Python 버전을 확인한 후 별도 환경과 고정된 의존성을 추가한다.
학습 원본·영상·가중치는 Git에 넣지 않는다. 동의가 없는 기록은 학습용 내보내기에서 제외한다.
