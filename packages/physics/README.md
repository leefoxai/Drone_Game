# 공유 비행 물리

클라이언트와 향후 서버가 함께 사용하는 순수 TypeScript 물리다.
DOM, Three.js, 화면 주사율, 실제 시계에 의존하지 않는다. 고정 시간 스텝과 SI 단위를 사용한다.

현재 physics_version=2, 고정 주기 240 Hz. `src/index.ts`는 6자유도 강체, 모터 추력/반토크,
지연, 각속도 PID, 항력, 중력, 배터리 모델이다. `src/assist.ts`는 쉬운 조종 보조기다.
`src/track.ts`에 게이트 교차·충돌 판정, `src/race.ts`에 랩 순서/무효 처리가 있다.
`src/clock.ts`는 화면 주기와 독립된 tick 누산기다. Three.js 의존성이 없다.
`profiles/racer5.json`에 SI 단위 값·출처·가정·회귀 목표를 분리했다.
목표값은 근사 모델의 개발 기준이며 실기체의 실측 검증을 뜻하지 않는다.
입력, 초기 상태, 기체 설정, 시드가 같을 때 재시뮬레이션 결과를 비교할 수 있어야 한다.
계산이 바뀌면 `physics_version`을 올리고 회귀 테스트 및 기록 호환성을 확인한다.
좌표계와 기록 계약은 `docs/data_spec.md`를 따른다.

테스트: 루트에서 `npm test -- tests/physics.spec.ts --workers=1`.
관성/공기 저항/프로펠러와 배터리는 단순화 모델이다. 지면 효과·난류·프로펠러 워시·접촉 응답은 미구현이며
지면/게이트 충돌 시 주행을 리셋한다. 여러 JS 엔진 간 동일성은 M2에서 추가 검증한다.
