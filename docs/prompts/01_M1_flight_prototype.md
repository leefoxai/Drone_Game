ROADMAP의 M1(비행 프로토타입)을 진행해 주세요. 먼저 계획만 보여 주고, 내가 "진행"이라고 하면 구현하세요.

물리 (packages/physics, physics_version 1)
- 쿼드콥터 6자유도: 모터별 추력·반토크, 모터 응답 지연, 공기 저항, 중력, 배터리 전압 강하
- Acro 모드: 스틱 → 목표 각속도(Betaflight식 rates), 내부 rate PID
- 기체 값은 JSON 프로파일로 분리. 기본값은 5인치 레이싱 쿼드 공개 스펙 기준, 출처를 주석으로
- 고정 스텝(예: 500Hz) + 렌더링 보간. 같은 입력이면 같은 결과

입력
- Gamepad API로 USB 조종기(조이스틱 모드)와 게임패드 지원
- 축 매핑·반전·캘리브레이션 화면(조종기마다 축 순서가 다름), 설정은 저장
- 키보드는 테스트용으로만

화면과 도구
- FPV 카메라(틸트·FOV 조절)와 3인칭 카메라 전환
- 게이트 5개짜리 트랙 1개, 충돌 시 리셋, 랩 타이머
- 실시간 튜닝 패널: rates, 카메라 틸트, 기체 프로파일 값
- 디버그 그래프: 스틱 입력 vs 실제 각속도, 스로틀 vs 추력

자동 테스트
- 호버 스로틀, 최대 상승 가속, 360° 롤 소요 시간이 프로파일 목표값 ±10% 이내
- 같은 입력 시퀀스를 두 번 돌리면 결과가 동일
- Playwright: 페이지가 뜨고 드론이 호버 상태로 안정

완료 조건: 내가 조종기로 트랙을 한 바퀴 돌 수 있고, 튜닝 값이 즉시 반영되며, 테스트가 전부 통과
